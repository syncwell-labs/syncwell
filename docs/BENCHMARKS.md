# Syncwell Benchmarks

Generated by `make bench` (test/bench.mjs). Single machine, server + clients in
one box, so these measure engine + loopback, not WAN. Reproduce with:

```
CLIENTS=50 DURATION_MS=3000 INTERVAL_MS=5 make bench
```

| metric | value |
| --- | --- |
| concurrent clients | 50 |
| publishes | 555 @ 200/s |
| delivered samples | 27195 (fan-out ×49) |
| sync latency p50 | 1.33 ms |
| sync latency p95 | 2.51 ms |
| sync latency p99 | 3.64 ms |
| max latency | 6.59 ms |
| delivery throughput | 9,065 msg/s |
| server RSS | 11.5 MB |

**Method:** 50 websocket clients join one room. One publisher updates a key
every 5 ms; the other 49 clients timestamp each
received update against its publish time (same process clock). Latency is the
publish→receive delta; throughput is delivered messages/second.
